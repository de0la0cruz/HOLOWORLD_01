# HOLOWORLD

An open-source portrait of a philosophy: ethos, vibe, personality, and the metaphysics of AntiGod — patristic rhizomatics, quantum-entangled parallel us-nesses, and HALO civilization, heaven as something built.

In the author's words: HOLOWORLD is a **civilization operating system** — the HALO thread is its core: values, rituals, and structures for a civilization, specified openly so others can inspect, test, and build on them.

## What's here

- **PHILOSOPHY.md** — the portrait: ethos, vibe, personality, philosophy, and a glossary of HOLOWORLD terms.
- **SPECS.md** — the build specs: contents, the rhizome graph (19 nodes, 30 edges), method, and how to rebuild or extend it without the author.
- **rhizome.html** — the interactive knowledge graph (open in a browser).
- **graph.json** — the graph as queryable data.

## Peer review

HOLOWORLD v1 is **open for peer review** — see [Issue #1: LOOKING FOR PEER REVIEWERS](https://github.com/de0la0cruz/HOLOWORLD_01/issues/1) and `REVIEW.md` for the review questions and ground rules. The review branch is `peer-review/holoworld-v1`. Feedback belongs on the issue or the pull request; cite the file and line you are challenging.

Everything is labeled as what it is — source, inference, or coinage (HALOGOD is flagged as the author's coinage, not source). That labeling is deliberate: the work asks to be judged on its receipts.
